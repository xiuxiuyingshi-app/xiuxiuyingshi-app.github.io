观影问答 · 关于 羞羞影视

以下是被问得最多的几件事，答案随站点改版同步修订。

羞羞影视的排片表多久更新一次？

每日 09:00 与 20:00 两次。遇节假日或片方临时调整，会在顶部红色滚动条里第一时间标出，不做静默修改。

为什么有些条目的链接打不开？

内页正在分批整理，暂时统一用 # 占位。已开放的内容在排片表中标注为「连载中」或「已完结」，其余状态为待开放。

榜单分数是怎么算出来的？

5 位编辑各自独立打分，去掉一个最高分与一个最低分后取平均，保留一位小数。参评人数不足 3 人时不计入总榜。

手机上浏览会不会很费流量？

整站只有一个 HTML 文件，海报用 CSS 渐变绘制而非位图，脚本不到 2 KB，首屏在 4G 网络下通常 1 秒内完成渲染。

怎么记住这个站？

站点地址是 https://xiuxiuyingshi-app.github.io ，把它加到浏览器书签或主屏即可；也可以直接使用页面底部的更新提醒。
